Sintesi
La mod costruisce un sistema abbastanza pulito in tre pezzi:
[on_actions (line 2)](C:/Users/condr/Documents/Paradox Interactive/Hearts of Iron IV/mod/sheep universal 1.19/common/on_actions/zzz_sheep_dynamic_invasion_on_actions.txt:2) aggiorna i dati quando un major AI è in guerra, ogni mese e allo scoppio di una guerra.
[evento `dynamic_invasion.1` (line 3)](C:/Users/condr/Documents/Paradox Interactive/Hearts of Iron IV/mod/sheep universal 1.19/events/zzz_sheep_dynamic_invasion_events.txt:3) calcola gli stati costieri nemici “validi” in base alla distanza dai porti propri o alleati.
Le due [ai_strategy (line 1)](C:/Users/condr/Documents/Paradox Interactive/Hearts of Iron IV/mod/sheep universal 1.19/common/ai_strategy/zzz_sheep_dynamic_distance_invasion.txt:1) bloccano o favoriscono invasioni navali usando quell’array.
Logica principale
L’evento svuota valid_naval_targets, raccoglie gli stati costieri controllati dal paese AI o dai suoi alleati non capitolati, poi cerca stati costieri nemici entro tre fasce: < 350, poi < 600, poi < 1200. La cosa importante è che passa alla fascia successiva solo se non ha trovato nessun bersaglio nella fascia precedente. Quindi non “somma” tutti i target entro 1200: sceglie la fascia più vicina che produce almeno un bersaglio.
Questo è probabilmente voluto: impedisce all’AI di lanciare invasioni lontane quando esistono bersagli navali più vicini.
Punti forti
Buona limitazione del carico: l’on_action gira solo su is_major = yes, is_ai = yes, has_war = yes.
L’array viene ricalcolato da zero, quindi non accumula bersagli vecchi.
Il blocco block_invasions_if_land_front_exists è sensato: se uno stato costiero nemico confina con territori propri o alleati, la mod prova a impedire invasioni navali inutili lì.
La strategia distanza ha sia freno forte (-999999) sia incentivo positivo (1000), quindi dovrebbe pesare parecchio sul comportamento AI.

Esatto, allora il problema non è “Dodecaneso sì/no”. È che la mod, dopo aver trovato qualsiasi bersaglio valido vicino, smette di cercare altrove.
Nel file eventi, questa variabile è il nodo:
[evento righe 31-34 (line 31)](C:/Users/condr/Documents/Paradox Interactive/Hearts of Iron IV/mod/sheep universal 1.19/events/zzz_sheep_dynamic_invasion_events.txt:31)
set_temp_variable = {
	temp_var = found_target
	value = 0
}
Poi il flusso fa:
cerca target entro 350
se ne trova almeno uno, found_target = 1
siccome found_target = 1, salta del tutto la ricerca entro 600
salta anche quella entro 1200
Quindi se il Dodecaneso entra nella prima fascia, Sicilia, Sardegna, Italia del sud o Normandia possono non entrare mai in valid_naval_targets. E siccome l’altro file dà -999999 a tutto ciò che non è in quell’array, l’AI viene praticamente proibita dal pianificare altri sbarchi.
La correzione giusta per quello che vuoi tu è: non usare le fasce come alternativa esclusiva. Il Dodecaneso deve restare valido, ma anche gli altri bersagli entro una distanza ragionevole devono entrare nell’array.
In pratica, nel file eventi conviene sostituire la logica a tre blocchi con una logica più semplice:
every_state = {
	limit = {
		is_coastal = yes
		controller = {
			has_war_with = ROOT
		}
	}
	save_event_target_as = target_enemy_state
	if = {
		limit = {
			ROOT = {
				any_of_scopes = {
					array = root_coastal_ports
					distance_to = {
						target = event_target:target_enemy_state
						value < 1200
					}
				}
			}
		}
		ROOT = {
			add_to_array = {
				array = valid_naval_targets
				value = event_target:target_enemy_state
			}
		}
	}
}
Così il Dodecaneso resta permesso, ma non “consuma” tutta la logica. La mod diventa: “blocca gli sbarchi troppo lontani”, non “scegli solo il teatro più vicino e ignora tutto il resto”.
Secondo ritocco consigliato: abbassare il blocco assoluto in [dynamic distance righe 16-23 (line 16)](C:/Users/condr/Documents/Paradox Interactive/Hearts of Iron IV/mod/sheep universal 1.19/common/ai_strategy/zzz_sheep_dynamic_distance_invasion.txt:16) da:
value = -999999
a qualcosa tipo:
value = -5000
o anche -1000, se vuoi lasciare più libertà all’AI vanilla. -999999 è praticamente un divieto totale; va bene per impedire follie, ma rischia di soffocare piani storici importanti.
